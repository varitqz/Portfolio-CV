# Jannik Richter — Interactive Portfolio

Static, dependency-free portfolio / interactive CV. Built for GitHub Pages and designed to work by simply opening `index.html`.

## Included

- Responsive single-page portfolio
- German / English toggle
- Dark / light theme
- Recruiter View (condensed mode)
- Keyboard command palette (`Ctrl/Cmd + K`)
- Interactive KQL lab drawer
- Interactive terminal commands
- Print stylesheet for **Print → Save as PDF**
- No trackers, cookies, frameworks or external fonts
- Accessibility basics: semantic sections, keyboard focus, reduced-motion support, skip link

## Local preview

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Publish with GitHub Pages

This repository is prepared for GitHub Pages. In GitHub, open **Settings → Pages → Deploy from a branch → main / root**.

## Privacy

The public portfolio intentionally shows only Hamburg, email, LinkedIn and GitHub rather than a street address or phone number. Detailed address/phone can remain in application documents sent directly to employers.
